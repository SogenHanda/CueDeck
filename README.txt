CUE DECK
1つのアプリでプロジェクトを切り替える舞台進行管理

起動: /Applications/CueDeck.app
アプリ名に作品名やバージョン番号を付ける必要はありません。

操作画面
  上部に「現在のイベント」と「次のCUE」を固定表示。
  担当別カードで「現在」「次のGO後」「その担当の次の変更」を確認できます。
  変わる状態を黄色、変わらない状態を継続として表示します。
  照明・音響・mocap・AI・出演者・技術。長い指示はカードの矢印で全文表示。

プロジェクト
  上部の作品名をクリック → 新規作成、複製、JSON/CSVから追加、作品切り替え。
  時計、実行済みCUE、担当状態、送信先は作品ごとに保存します。
  作品の切り替え・作成はHOLD中。開いたときはHOLD・OSC出力OFF。
  以前の保存データは初回起動時に自動移行し、元ファイルも保管します。

最新版シート
  31イベント。開場前 -1:00:00、客入り -0:30:00、前説 -0:05:00。
  予定はstart time列。最初の時計は-1:00:00、時計0が指示音声の予定。
  ???の2件は時刻未定。初期CUEは全件手動、OSCメッセージは未設定。
  同梱の 最新版.cuedeck.json もアプリ内のプロジェクト画面から追加できます。

基本操作
  START/RESUME → SpaceまたはGO → EscまたはHOLD。
  行の選択は確認用。GO対象はNEXTです。
  「1つ戻す」で直前のCUEを実行前へ戻せます。複数回に対応。
  外部機器の音・照明は巻き戻りません。
  「編集・OSC」ボタンで右パネルを開き、CUEや送信設定を変更できます。

CSV更新
  GoogleスプレッドシートのCUEタブをUTF-8 CSV/TSVでダウンロード。
  現在作品の更新: … → この作品をCSV / TSVで更新
  別作品への追加: プロジェクト → CSV / TSVから追加
  CSVでは自動実行・OSCメッセージを引き継ぎません。再設定してください。
  設定を保持する作品の移動にはJSONを使ってください。

保存先
  ~/Library/Application Support/CueDeck/
    Projects.json                    プロジェクト一覧と最後の作品
    Projects/<ID>/Show.json           CUE、OSC設定など
    Projects/<ID>/Runtime.json        時計、実行済みCUE、ログ
    Projects/<ID>/ProjectBackups/     更新前の作品JSON
    Projects/<ID>/RunBackups/         リセット・戻す・更新前の進行
  異常終了時の時計差は最大約2秒。復帰はHOLD・出力OFFです。

開発
  Source/ に全ソースがあります。外部依存なし、SwiftUI/AppKit。
  ./build.sh は build/CueDeck.bundle を生成します。作業用アプリは増やしません。
  ./install.sh は /Applications/CueDeck.app を更新します。先にアプリを終了してください。
  ./verify.sh で重要な動作を検証できます。
  ビルドとインストールにはXcode Command Line Toolsが必要です。

注意
  担当の先読みはCUEの並び順のプレビューです。並行AUTOは別表示します。
  OSC/UDPの送信成功は受信機の実行確認ではありません。
  会場の機器構成で、事前に送受信と通し稽古を確認してください。

詳しい手順は 操作ガイド.html を参照してください。

URL登録・更新ボタン
  上部のリンクアイコン、または … → シートURLを登録・変更
  開いているCUEタブのURL（gid付き）を貼り、URLを保存します。
  URLはプロジェクトごとに保存されます。

  上部の「シートを更新」 → 最新版を取得 → 変更内容を確認 → バックアップして更新
  変更がなければ「確認完了」で時計・進行を維持します。
  変更を反映する場合は作品・進行をバックアップし、未実行・HOLD・OSC OFFになります。
  一致するCUEのOSC・自動実行設定は引き継げます（チェックで切り替え）。
  重複などで判断できない行は設定を引き継がず、削除された基準CUEなどは警告して手動に戻します。
  本文・予定時刻・担当状態・メモはシート側を優先します。
  本番進行中・未保存編集がある間は更新できません。
  取得失敗・中止では現在の作品を維持します。
  最終確認・反映日時も保存します。
  ログインなしでCSVを取得できるGoogleシートが対象。現在のシートで直接取得を確認済みです。
  限定公開で権限が必要な場合はエラーを表示します。共有設定は変更しません。
