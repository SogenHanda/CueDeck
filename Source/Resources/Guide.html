CUE DECK

1つのアプリで作品を切り替える、舞台の進行管理。

アプリは1つ

起動するのはアプリケーションフォルダの CueDeck です。作品ごと・更新ごとにアプリを増やす必要はありません。作品名をクリックするとプロジェクト一覧を開けます。旧データは初回起動時に自動移行します。

現在・次のCUE・次の担当変更

  • 上部左は実際に最後にGO / AUTO実行したイベント、右は次のGO対象です。左の一覧の行を選ぶだけでは現在やGO対象は変わりません。
  • 担当カードには現在と次のGO後を並べます。変わる値は黄色、空欄・同一の値は継続として表示します。初回GO前の現在状態は「状態未確定」です。
  • カード下部のこの担当の次には、その担当の状態が変わる、または担当CUE番号の指定がある次のイベントを表示します。直後のCUEで照明が変わらない場合も、後ろの照明CUEまで先読みできます。変更予定がなければその旨を表示します。
  • 照明・音響・mocap・AI・出演者・技術に対応します。カード右上の矢印で長い指示を全文表示できます。
  • 担当の先読みはCUEの並び順によるプレビューです。人がGOする時刻や外部機器の実状態を保証するものではありません。並行AUTOが設定されている場合は「次のCUE」に残り時間も別表示します。

新しいプロジェクト

  1. 画面上部の作品名、または「… → プロジェクトを作成・切り替え」を押します。
  2. 作品名を入力して「空のプロジェクトを作成」、または「現在の作品を複製」を選びます。作品JSON・CSV / TSVから追加することもできます。
  3. 一覧の作品を押すと切り替わります。時計、実行済みCUE、状態、OSC送信先はプロジェクトごとに保存します。再起動では最後に開いた作品を復元します。

切り替えと作成はHOLD中に行います。未保存の編集があれば先に保存または破棄してください。作品を切り替えると必ずHOLD・OSC出力OFFになります。作品名の変更は右の編集パネル→OSCタブから可能です。プロジェクトを複製するとCUEとOSC設定は複製し、進行は未実行になります。

進める・止める・戻す

START / RESUMEで時計を開始、GO / SpaceでNEXTのCUEを実行、HOLD / Escで時計と自動CUEを止めます。HOLDは外部機器の音声・映像をSTOPする命令ではありません。入力欄の編集中はSpaceを文字入力に使います。

1つ戻すは直前に実行したCUEを未実行に戻し、次のGOで再実行できる状態にします。複数回戻せます。状態を実行履歴から再計算し、時計を維持、OSCをOFFにします。戻した自動CUEも自動再発火せずGOを待ちます。スキップは実行ではないのでこの操作の対象外です。

任意の行に戻るときは、編集パネルで行を選択し「その他 → ここから再開 / ジャンプ」。その行以降を未実行にし、前の未実行行をスキップします。時計は維持し、OSCをOFFにします。外部機器の状態は巻き戻しません。

開演前と上演時計

予定時刻は HH:MM:SS、MM:SS、秒のいずれかで入力できます。開場前は -1:00:00、客入りは -0:30:00 のような負の時刻に対応しています。最初の開始値は「0」と「最も早い予定時刻」のうち早い方です。今回の作品は−1時間から始まり、時計0が「指示音声」の予定時刻です。

「… → 新しい上演 / リセット」で進行を初期化すると、作品の開始値に戻ります。下部の「時計を調整」からHOLD中に時計を合わせられます。実行済みCUEの時刻より前には戻せません。

自動CUE

  • 「手動GO」は予定時刻を目安に表示するだけで、自動実行しません。
  • 「上演時計」は指定時刻に自動実行。「CUEからの時間」は、指定した前のCUEが実際に実行されてから計ります。相対秒数は0以上です。
  • 自動CUEは手動CUEの待機中も独立して動きます。基準をスキップすると相対CUEは基準待ちになります。
  • 2秒を超える時計の中断ではHOLDに移り、中断時間を加算しません。0.6秒を超過した自動CUEもHOLDします。該当CUEを手動実行するかスキップし、時計を確認して再開してください。

URLからシートを更新する

  1. 上部のリンクアイコン、または「… → シートURLを登録・変更」で設定画面を開きます。プロジェクト画面からもURLを登録できます。
  2. GoogleスプレッドシートでCUEのタブを開いたURLを貼り、「URLを保存」。タブを特定するgidも保存します。URLはプロジェクトごとに保持します。
  3. 上部の「シートを更新」を押すと、登録URLからCSVを直接取得し、追加・変更・削除の一覧を表示します。
  4. 確認後「バックアップして更新」を押すと反映します。旧作品と進行をバックアップし、時計・実行済みCUEを初期化、HOLD・OSC出力OFFで開きます。変更がなければ「確認完了」で確認日時だけ保存し、時計と進行を維持します。

一致するCUEのOSC・自動実行設定を引き継ぐチェックが初期値です。イベント名と進行CUEなどで一意に対応づけできる行のID・OSC・トリガー設定を維持します。重複して判断できない行には設定を割り当てません。基準CUEが消えた相対CUE、予定時刻が未定になった時計CUEは、警告して手動に戻します。シートの本文・時刻・担当状態・メモを優先します。

ネットワークエラー・中止・不正な応答では現在の作品を変更しません。取得中に別の編集が行われた場合も、古い結果の反映を止めます。本番進行中や未保存編集がある間は更新ボタンを無効にします。確認画面を閉じるまでは進行開始・作品切り替えも止めます。

ログインなしでCSVを取得できるGoogleシートに対応します。現在の作品のURLは取得確認済みです。限定公開などで閲覧権限が必要な場合は、エラーを表示し、従来のCSV取り込みを利用できます。共有設定はアプリから変更せず、ブラウザのログイン情報やCookieも使いません。最終確認・最終反映日時は作品と一緒に保存します。

CSVファイルからの更新・取り込み

GoogleスプレッドシートでCUEタブをCSV / TSVとしてダウンロードしてください。既存作品の更新は「… → この作品をCSV / TSVで更新」、別の作品として追加する場合はプロジェクト画面の「CSV / TSVから追加」を選びます。自動同期は行いません。URLを登録すれば上部の更新ボタンから直接取得できます。

今回のシートの見出し、または「イベント名」「開始時刻」「音響」「照明」「技術」「mocap」「AI」「竹本」「富士夫」「萌」「花形」「メモ」などに対応します。sogen cueは現在・次のイベントのCUE指示、technicalは技術状態として取り込みます。end time、time(min)などはメモに保持します。セル内改行、カンマ、引用符に対応し、文字コードはUTF-8です。

予定時刻はstart time列を使います。「???」の2件は時刻未定として手動GOにします。CSV / TSVは全CUEを手動・未実行・OSCメッセージなしで読み込みます。既存のOSC・自動実行設定を持ち運ぶ場合は作品JSONを書き出し、JSONから追加・更新してください。現在作品を更新する前には作品と進行をバックアップします。

OSC

  1. 編集パネル→OSCタブで送信先IPv4とポートを設定します。初期作品の候補はNetworkシートのAI=.101、Mocap=.102、Light=.103、Sound=.104（192.168.220.x、ポート13001）です。接続確認済みを意味しません。
  2. CUE編集下部でOSCメッセージのアドレスと引数を設定します。int32 / float32 / ASCII文字列に対応。アドレスは受信アプリの仕様に合わせてください。
  3. HOLD中に出力をONにし、必要ならテスト送信。本番出力ONのGO / AUTOは実際に送信します。OFFではログだけ記録します。

UDPの送信成功は受信・実行の確認ではありません。複数メッセージは別パケットで送り、一括の実行は保証しません。送信エラーではHOLD・出力OFFにし、自動再送しません。すでに一部が送信されている場合があります。会場機器で事前に動作を確認してください。

保存とバックアップ

保存先は ~/Library/Application Support/CueDeck/。Projects.jsonに一覧・最後の作品、Projects/作品ID/に作品のShow.jsonと進行のRuntime.jsonを保存します。リセット・戻す・更新前の進行は各作品のRunBackups、更新前の作品はProjectBackupsです。移行前のルートにあったファイルは保管します。

作品編集は「変更を保存」、進行はGO / HOLD / 約2秒ごとのチェックポイントで保存します。異常終了では最大約2秒の時計差があります。送信前に実行を記録するため、強制終了の瞬間には記録と実送信に差があり得ます。機器側も確認して再開してください。

作品JSONには進行を含めません。実行ログはCSVで書き出せます。別作品の保存データが不正な場合は切り替えを止め、現在の作品を維持します。

対応環境

macOS 14以降 / Apple Silicon。オフライン動作。実行中はアイドルスリープを抑制しますが、ふたを閉じる・強制スリープ・OS更新などは防ぎません。
